# ela-personal-skills

אוסף הסקילים האישיים של אלה — נאסף מהריפוזיטורים `new-businesses`, `Trips` ו-`halloween-holland-2026`, כדי שיהיו זמינים ממקום אחד בכל ריפו ובכל session.

## עסקי ואסטרטגיה (biz-*)
- **biz-37signals-way** — בניית מוצרים רזים ונחרצים בשיטת 37signals ("Getting Real", "Rework").
- **biz-cold-start-problem** — הפעלה והרחבה של מוצרים רשתיים לפי מסגרת "The Cold Start Problem".
- **biz-hundred-million-offers** — בניית הצעות בלתי ניתנות לעמוד בפניהן (Value Equation, בונוסים, הבטחות).
- **biz-improve-retention** — אבחון ותיקון בעיות שימור (B=MAP).
- **biz-jobs-to-be-done** — זיהוי ה"עבודה" שהלקוח שוכר את המוצר לעשות.
- **biz-lean-analytics** — בחירה וביקורת מדדי סטארטאפ (Lean Analytics).
- **biz-lean-startup** — MVP, ניסויי Build-Measure-Learn, החלטות pivot.
- **biz-mom-test** — שיחות לקוחות בלי להטות תשובות (Mom Test).
- **biz-monetizing-innovation** — תמחור לפי נכונות לשלם מאומתת.

## שיווק (mkt-*)
- **mkt-ai-seo** — הופעה והפניה במענות AI (ChatGPT, Perplexity, AI Overviews).
- **mkt-churn-prevention** — הפחתת נטישה.
- **mkt-copywriting** — כתיבה/שכתוב תוכן עמודים.
- **mkt-cro** — שיפור שיעורי המרה.
- **mkt-customer-research** — מחקר לקוחות וסינתזה.
- **mkt-directory-submissions** — רישום במדריכי SaaS/AI/MCP.
- **mkt-free-tools** — תכנון כלים חינמיים כשיווק.
- **mkt-launch** — תכנון השקת מוצר/פיצ'ר.
- **mkt-onboarding** — onboarding והפעלה.
- **mkt-paywalls** — paywalls ורגעי upgrade.
- **mkt-pricing** — תמחור ואריזה.
- **mkt-programmatic-seo** — עמודי SEO בקנה מידה מתבניות.
- **mkt-seo-audit** — אבחון וביקורת SEO.

## כלליים
- **systematic-debugging** — שיטת דיבוג שיטתית לפני הצעת תיקונים.
- **truth-first-advisor** — יועץ אמת לא-מחניף, כולל "מצב מועצה" להחלטות גדולות.
- **ui-ux-pro-max** — אינטליגנציית עיצוב UI/UX לווב/מובייל/דסקטופ.

## התקנה
1. פתחי את הקובץ `ela-personal-skills.plugin` בשיחה (יוצג כתצוגה מקדימה).
2. לחצי על הכפתור להתקנה בחשבון שלך.
3. מרגע ההתקנה, כל הסקילים האלה יסתנכרנו אוטומטית ל-`~/.claude/skills/synced` בכל session עתידי, בכל ריפו — בלי תלות בריפו הנוכחי.
